Setup (needs Node.js 18+):
1. cd mh333-server
2. npm install
3. Linux/Mac: ADMIN_TOKEN=yourSecret npm start
   Windows:   set ADMIN_TOKEN=yourSecret && npm start
4. Game:  http://localhost:3000
   Admin: http://localhost:3000/admin   (enter the same token)
Put on a VPS/Render/Railway to let everyone play on one shared round.
